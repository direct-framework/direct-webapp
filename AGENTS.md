# Agent context

These guides cover Python/Django, Django templates, and styling. JavaScript
architecture is outside their scope.

Before changing application code, read [Django architecture](docs/agents/architecture.md)
and [Development conventions](docs/agents/development.md).

- For tests, behavior changes, or validation before handover, read
  [Testing](docs/agents/testing.md).
- For templates, forms rendered as HTML, or styling, also read
  [Templates and styling](docs/agents/templates.md).

Keep changes scoped to the request and preserve existing behavior unless a change
is agreed. Discuss new dependencies and substantial architectural changes first.

## Agent workflows

### Issue tracker

Issues and specs live as markdown files under `.scratch/<feature>/`.
See [Issue tracker](docs/agents/issue-tracker.md).

### Domain docs

For framework or self-assessment work, read [Domain docs](docs/agents/domain.md)
for terminology and sources.
